# EntityFrameworkCore.Sqlite.Legacy

NuGet-focused repository for legacy encrypted SQLite access through EF Core.

## Contains

- `src/EntityFrameworkCore.Sqlite.Legacy`
- `src/Sqlite.LegacyBridge.Ado`
- `src/Sqlite.LegacyBridge.Client`
- `src/Sqlite.LegacyBridge.Protocol`
- `tests/Plu.LegacyBridge.Verify`

## Publish

- GitHub Actions workflow: `.github/workflows/nuget-entityframeworkcore-sqlite-legacy.yml`
- Configure secret `NUGET_API_KEY` in repository secrets.
